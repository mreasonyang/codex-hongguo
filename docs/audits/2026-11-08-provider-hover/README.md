# 悬停选源浮层验证

左上角播放图标改为悬停展开片源浮层。点击图标只打开浮层，点击具体 Provider 才切源；单源时不展开。触屏保留点击打开，键盘支持方向键打开／选择、Enter 确认及 Esc 关闭。

- `npm test`：198 项，192 通过、0 失败、6 项 Windows 专属测试在 macOS 跳过。
- 自动化覆盖悬停和点击不直接切源、点击条目切源、悬停不抢焦点、移出延时收起／重新移入取消收起、键盘打开及 Esc 返回按钮、单源限制。
- 内置浏览器使用实际构建 UI、独立临时 Store/Service/ProviderRegistry 和固定测试片库，验证鼠标悬停展开、跨过图标与浮层间隙后继续操作、移出自动收起、点击黄果后才切换、键盘切回红果及 Esc 关闭。
- 搜索框有焦点时，纯悬停后焦点仍在搜索框，片源仍为红果。
- 检查 397px 浅色／深色，以及 320px 深色浮层；320px 下页面宽度为 320px，无横向溢出。
- UI 资源升级至 v23，保留 v22 及旧 URI 读取兼容。
