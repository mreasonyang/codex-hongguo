# Provider 启用配置验证

播放器设置新增 Provider 开关。默认仅启动红果，黄果和本地 Provider 需手动开启并保存；配置持久化并跨聊天同步。启用与当前选中分开，图标只在已经启用且可用的片源之间切换。

## 自动化回归

- `npm test`：196 项，190 通过、0 失败、6 项 Windows 专属测试在 macOS 跳过。
- 默认只创建红果实例；黄果开启、停用、重新开启时实例与取消信号正确释放。
- 本地插件发现时不导入未启用入口；加载失败不影响红果。
- 配置持久化、两个服务实例同步、非法配置拒绝、停用后默认源回退及观看进度保留。
- 停用后清除旧播放授权、分集、推荐选择和浏览器选择；旧分集缓存不能再次授权播放。
- 播放器设置表单开启／停用黄果，关闭当前片源后回到红果。
