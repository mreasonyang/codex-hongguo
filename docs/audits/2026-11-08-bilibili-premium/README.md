# Bilibili 原生会员播放接入

分支 `feat/video-source-adapters`，基线 `0f4c370`。用户本轮选择先完成实现与自动回归，真实大会员专属番剧因没有可用会员账号而暂缓验收。

## 变更

- 已登录调用向 amagi 6.6.0 传入真实登录态，启用其原生账号检查、WBI 签名及会员选流；不再用空 Cookie 强制匿名 H5 分支，也不再覆盖会员请求为 480p。
- SDK 私有构建中的 Axios 使用异步调用上下文绑定当前 Provider 的受限传输，内部账号与签名请求同样受域名、大小、超时、取消限制。并发账号互不串用，宿主其他 Axios 实例不受影响。
- 已登录优先选择原站授权返回、大小预算内的较高清晰度 AVC/AAC；超过预算自动降档。匿名策略保留。会员身份不绕过试看、地区、购买权益或 DRM 检查。
- 媒体缓存绑定不含凭据的账号版本，登录后可立即重试旧的试看失败并重新选流，退出后不能复用旧账号媒体。准备期间账号变更的旧结果不会发布。旧版红果缓存迁移后继续命中。

## 自动验收

- 全量 218 项：212 通过、6 项 Windows 测试跳过、0 失败，见 `tests.json`。
- 新增 10 项测试使用真实的编译 SDK，模拟账号权益与网络响应，验证原生会员参数、签名、普通/匿名分支、并发账号隔离、取消、授权失败和清晰度降档。
- 模拟会员流程接入真实 AVC/AAC 媒体夹具，完成双轨获取、FFmpeg 合流及音视频解码；覆盖登录解除旧错误缓存、退出拒绝旧媒体，以及准备中切换账号的竞争情况。此项不是真实会员专属番剧实测。
- 最终包的真实匿名 B 站整集播放、MCP 分片解码、跨进程续播、试看拒绝及停用撤销结果见 `packaged-bilibili.json`。
- 最终包的真实匿名二维码流程见 `packaged-auth.json`，红果 macOS 隔离安装与真实播放解码回归见 `installed-hongguo.json`，产物与源码匹配证据见 `artifacts.json`。

真实会员专属内容、4K/HDR/杜比/DRM 以及 Windows/Linux 原生桌面不在本轮已验收范围内。没有更新用户现有安装，没有合并或发布。
