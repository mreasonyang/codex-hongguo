---

帮助用户在当前安装环境完成红果短剧配置。该插件用于本机执行的 Codex 对话，不需要红果账号、API Key 或浏览器自动化权限。

从此 SKILL.md 的实际位置向上两级确定插件根目录。在 macOS/Linux 用 `sh "<插件根目录>/bin/run-node" check` 检查；Windows x64 试用版在 PowerShell 用 `& "<插件根目录>\bin\run-node.exe" check`。启动器自动寻找 Node，并检查版本及 SQLite。正确引用包含空格的路径。脚本只输出 Node、进度库、FFmpeg 的环境元数据，以及固定的 Hooks 人工授权核对提示，不检测授权状态，不发送模型请求。当前 npm 发行包仅开放 macOS/Linux；Windows 原生启动器随离线包提供，完整桌面验收通过前仍为试用。

- 需要 Node.js >=22.16。播放组件由插件自动下载、校验并缓存，无需用户自行安装 FFmpeg。首次需要联网；准备失败时检查网络并重新运行 `npx @kyun.si/codex-hongguo@latest setup`。特殊安装可使用 HONGGUO_NODE、HONGGUO_FFMPEG、HONGGUO_CODEX 指定程序；不要修改用户其他插件、认证或网络配置。
- Hooks 授权不执行检测。固定提示用户打开 Codex「设置 → Hooks → 红果短剧」，人工检查、信任并启用 UserPromptSubmit、Stop、Interrupt。不得自动宣称已授权或无需重复授权，不读取或写入信任记录，不把历史回合事件当成授权证明。

告诉用户从新本地对话的右侧 ＋ 搜索“红果”，或在“更多工具”的“插件和 MCP”分组打开红果短剧。点击推荐或搜索结果即可开播，默认静音；打开扬声器出声。未完成 Hooks 配置时仍可手动观看。

当用户选择验证回合联动时，在真实本地对话进行中打开面板并点播，观察回合结束或中断后是否暂停，再点普通播放键检查能否从原处继续。没有实际观察到视频暂停，就将这一项保留为待验证。结束时简短说明播放环境与仍需用户人工核对的 Hooks 授权事项，避免把检查通过当成完整桌面 E2E。
